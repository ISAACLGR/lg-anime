# Opções de Hosting Gratuito

## Backend (Node.js/Express)

### 1. Render (Recomendado)
- **Plano**: Web Service gratuito
- **Limites**: 512MB RAM, sleep após 15min inatividade
- **Suporta**: Bitbucket, GitHub
- **Banco**: PostgreSQL grátis
- **URL**: https://render.com

### 2. Glitch
- **Plano**: Totalmente grátis
- **Limites**: 2000 horas/mês, sleep após inatividade
- **Suporta**: GitHub
- **URL**: https://glitch.com

### 3. Replit
- **Plano**: Hacker Plan grátis para devs
- **Limites**: Sleep após inatividade
- **Suporta**: GitHub
- **Banco**: PostgreSQL grátis
- **URL**: https://replit.com

### 4. Fly.io
- **Plano**: 3 VMs grátis (256MB cada)
- **Limites**: Fica ativo sem sleep
- **Suporta**: Docker
- **URL**: https://fly.io

## Frontend (React Native/Expo)

### 1. Expo Application Services (EAS)
- **Plano**: Build gratuito
- **Limites**: 1 build por mês no plano gratuito
- **URL**: https://expo.dev

### 2. Expo Go (Desenvolvimento)
- **Plano**: Totalmente grátis
- **Limites**: Apenas para desenvolvimento/teste
- **URL**: https://expo.dev/client

### 3. Netlify (Web)
- **Plano**: Totalmente grátis
- **Limites**: 100GB bandwidth/mês
- **Suporta**: GitHub, Bitbucket
- **URL**: https://netlify.com

### 4. Vercel (Web)
- **Plano**: Hobby gratuito
- **Limites**: 100GB bandwidth/mês
- **Suporta**: GitHub, Bitbucket
- **URL**: https://vercel.com

## Recomendação para seu Projeto

**Backend**: Render (aceita Bitbucket, plano gratuito)
**Frontend**: Expo EAS (build gratuito) + Expo Go (teste)

## Banco de Dados Gratuito

### 1. Neon PostgreSQL
- **Plano**: Serverless gratuito
- **Limites**: 0.5GB, 100h/mês
- **URL**: https://neon.tech

### 2. Supabase
- **Plano**: 500MB grátis
- **Limites**: 2 projetos, 500MB cada
- **URL**: https://supabase.com

### 3. PlanetScale MySQL
- **Plano**: 5GB grátis
- **Limites**: 1 bilhão de leituras/mês
- **URL**: https://planetscale.com
